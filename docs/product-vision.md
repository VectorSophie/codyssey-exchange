# Codyssey Exchange — 제품 비전

## 문제 재정의

코디세이 학습 활동에는 이미 데이터가 있다(과제 상태, 평가 요청, 출입 기록, 경험치). 문제는 데이터 부재가 아니라 **설명 구조의 부재**다.
기존 트래커들은 각자 자기 영역(과제/평가/출입)의 "현재 스냅샷"만 보여준다. 그래서 다음 질문에 답할 수 없다:

- 지금 병목은 과제 자체의 난이도 때문인가, 평가 공급 부족 때문인가?
- 내가 다음에 어떤 과제를 선택하면 Level 5 시험까지 가장 빨리/안전하게/대기 없이 도달하는가?
- 이 수치는 공식 API가 확인해준 값인가, 우리가 추정한 값인가?

Codyssey Exchange는 이 세 트래커의 데이터를 시간 축을 가진 하나의 모델로 통합하고, "수요-공급-병목-경로"라는 경제 시장의 설명 문법을 빌려 답한다. 실제 금융 기능(매수/매도/원화 가격)은 만들지 않는다 — 빌리는 것은 오직 **정보 구조**다.

## 경제 은유 매핑 (확정)

| 경제 개념 | Codyssey Exchange 대응 |
|---|---|
| 자산/투자 대상 | 과제(Quest) |
| 비용 | 학습시간 |
| 수요 | 평가 요청 |
| 공급 | 평가 가능 슬롯 + 평가자 활동 |
| 유동성 부족 비용 | 평가 대기시간 |
| 진척 가치 | PASS, 경험치, 레벨 상승, 후속 과제 해제 (포인트는 평가 요청·수행의 화폐라 진척이 아님 — DATA.md 12.8절) |
| 위험 | 재평가, 실패 가능성 |
| 기회비용 | 한 과제를 고름으로써 미루는 다른 과제의 진척 |

## 핵심 질문 (제품이 반드시 답해야 하는 것)

1. 지금 어느 과제에서 학습자와 평가 요청이 정체되고 있는가
2. 어떤 시간대에 평가 수요가 공급을 초과하는가
3. 특정 과제는 평균적으로 얼마나 많은 시간과 대기를 요구하는가
4. 어떤 과제가 다음 레벨/시험 조건에 가장 크게 기여하는가
5. 내 현재 상태에서 Level 5까지 어떤 과제를 어떤 순서로 하는 것이 적합한가
6. 가장 빠른/가장 안전한/대기가 적은 경로는 어떻게 다른가
7. 계산에 쓰인 데이터·규칙 중 무엇이 공식 확인이고 무엇이 추정인가

## 이름

"Codyssey Exchange"를 그대로 사용한다. 조사 중 발견한 대안 후보("Codyssey Ledger", "Codyssey Terminal")는 국내 증권시장 은유("Exchange"="거래소")와의 정합성이 더 낮아 채택하지 않는다. 이름 논의로 구현을 지연하지 않는다는 원칙에 따라 확정.

## 스코프 경계 (하지 않을 것)

- 실제 화폐/투자수익률 시뮬레이션, 매수·매도 UI
- 개별 평가자를 공개적으로 낙인찍는 기능
- 무작위 엔드포인트 퍼징, 권한 우회, 타 사용자 시험결과 강제 조회
- [[privacy-threat-model]]에서 정의한 비공개 경계를 넘는 실명/세션/코멘트 원문의 공개 저장소 커밋

## 성공 기준 (MVP)

- 과제 시세/과제 상세/평가 시장/시장 개요가 실제 데이터(Quest/EV Tracker 공개 저장소 조인)로 동작 — 달성
- 모든 지표에 confirmed/observed/inferred 표시가 붙어 있음
- 내 전략 페이지에서 실제로 "다음에 뭘 해야 하는가"에 대한 근거 있는 답을 받을 수 있음
