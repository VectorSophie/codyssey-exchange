# 인터페이스 레퍼런스 조사

Codyssey Exchange의 화면 설계에 앞서 조사한 한국 증권시장/데이터 터미널류 서비스의 **정보 문법**을 정리한다.
이 문서는 각 서비스의 시각 자산을 복제하기 위한 것이 아니라, "정보를 어떤 구조로 배치하고 어떤 순서로 탐색하게 하는가"를 추출하기 위한 것이다.
Codyssey Exchange는 여기서 정보 문법만 가져오고, 로고·고유 색상·컴포넌트 배치·아이콘·차트 스타일은 독자적으로 설계한다.

## 조사 대상

- 네이버 금융 (국내증시 종합 시황, 종목 상세)
- 토스증권 (WTS 종목 상세, 스크리너, 관심종목)
- KRX 정보데이터시스템 / KRX 데이터마켓플레이스
- 한국 증권사 공통 HTS/MTS 관습 (호가창, 체결 강도, 등락 색상)
- Token Terminal, Dune Analytics (온체인 데이터 터미널 — 지표 정의와 스크리너 구조 참고)
- Codecademy 관리자 학습 리포트 (prerequisite/학습 경로형 서비스)

## 공통 정보 문법 (Codyssey Exchange가 가져올 것)

| 문법 | 증권 서비스에서의 형태 | Codyssey Exchange 매핑 |
|---|---|---|
| 시장 전체 요약 | 코스피/코스닥 지수, 등락 종목 수 | 시장 개요 — 학습활동지수, 병목확산지수 |
| 개별 종목 탐색 | 종목 리스트 → 종목 상세 | 과제 시세 → 과제 상세 |
| 시간에 따른 변화 | 일봉/분봉 차트, 전일 대비 | 상태 전이 차트, 최근 7/30일 변화 |
| 수요와 공급의 깊이 | 호가창 (매수/매도 잔량) | 평가 시장 — 시간대별 수요/공급 |
| 비교와 스크리닝 | 종목 스크리너, 필터, 정렬 | 과제 시세의 필터/정렬/비교(최대 4개) |
| 관심 대상 저장 | 관심종목 | 관심 과제 |
| 위험과 신뢰도 표시 | 거래정지, 관리종목, 투자유의 배지 | 표본 부족, 추정치, 데이터 신뢰도 배지 |
| 데이터 출처와 최신성 | 시세 지연 고지("15분 지연") | 데이터 최신성, 수집 시각 |

## 화면별 관찰

### 시장 전체 요약 (네이버 금융 스타일)
- 최상단에 지수 두세 개 + 등락 방향 색상, 등락 종목 수 막대(상승/보합/하락 카운트)를 배치해 "지금 시장이 어느 쪽으로 기울어 있는가"를 3초 내에 전달한다.
- 그 아래는 표 중심 리스트(거래상위, 상승률상위 등 탭 전환형 테이블). 카드가 아니라 테이블이 기본형이다.
- 정보 밀도가 높고, 폰트 크기는 작다 — 화면을 스크롤 없이 훑을 수 있게 만드는 것이 목적.
- Codyssey Exchange 적용: 시장 개요 최상단에 지표 3~5개(학습활동지수, 병목확산지수 등)를 요약 스트립으로 배치하고, 그 아래 "최근 개선/정체 과제 Top N" 테이블을 둔다.

### 종목 스크리너 (토스증권/네이버 금융 공통)
- 열 커스터마이징, 필터 조합, 저장된 화면 구성이 핵심. 토스증권은 패널 드래그/리사이즈/저장까지 지원하는데, 이는 Codyssey Exchange MVP 범위를 넘는 과한 기능이므로 채택하지 않는다.
- 대신 "필터 프리셋 저장 + 열 선택"이라는 핵심 문법만 가져온다.
- Codyssey Exchange 적용: 과제 시세 페이지의 저장된 필터, 사용자 정의 열, "필수 과제만/Level 5 기여만/대기 짧은 순" 같은 프리셋.

### 종목 상세 (호가창 포함)
- 호가창은 "매수 잔량 | 가격 | 매도 잔량"을 가격대별로 나열해 수요·공급의 깊이를 보여준다. 이 구조 자체(시간/구간별 수요-공급 대비)는 평가 시장에 의미 있게 대응된다: 시간대별 평가 요청 수 vs 같은 시간대 열린 슬롯 수.
- 다만 실제 매수/매도 주문을 흉내내는 클릭형 주문 UI는 만들지 않는다 — Codyssey Exchange에는 "주문"이라는 행위가 없다.
- Codyssey Exchange 적용: 과제 상세의 평가 수급 섹션에 시간대 x 요일 히트맵 또는 막대 형태로 수요/공급을 병렬 배치한다. 호가창의 "레이아웃 문법"만 차용하고 클릭 주문 기능은 제외한다.

### Token Terminal / Dune 스타일
- 지표 하나하나에 명시적 정의와 계산식 링크가 붙어 있고, 지표 사전(metric glossary)이 별도 페이지로 존재한다.
- 대시보드 간 프로토콜 비교가 테이블 형태로 제공되어, "이 지표를 여러 대상에 대해 한 번에 비교"하는 문법이 뚜렷하다.
- Codyssey Exchange 적용: 데이터 센터의 metric dictionary, 과제 비교(최대 4개) 기능이 이 문법에서 왔다.

### Codecademy류 학습 리포트 / prerequisite graph
- 진척을 단일 퍼센트가 아니라 "선행조건 그래프 위의 위치"로 보여준다. 완료/진행중/잠김 노드 색상 구분이 명확하다.
- Codyssey Exchange 적용: 레벨과 시험 페이지의 조건 그래프(완료/진행/실행가능/잠김/조건미확인/시험/레벨 노드).

## 모바일 vs 데스크톱
- 증권 서비스들은 데스크톱에서 정보 밀도를 최대화하고, 모바일에서는 탭 전환 + 단일 컬럼으로 축소한다. 정보를 줄이는 게 아니라 화면 전환 단계를 늘려서 밀도를 유지한다.
- Codyssey Exchange는 데스크톱 우선(1440px)으로 설계하고, 모바일(390px)은 MVP에서 핵심 화면(시장 개요, 내 전략)만 우선 반응형 대응한다.

## 하지 않을 것 (브리프 7절과 결합)
- 실시간 틱처럼 보이는 가짜 갱신 애니메이션
- 캔들차트 (OHLC에 대응하는 데이터가 없으므로 사용 안 함 — 완료시간 분포 등은 박스플롯/히스토그램으로 표현)
- 매수/매도 버튼, 잔고, 원화 표시
- 검은 배경 + 형광색 티커
